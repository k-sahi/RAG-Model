# Mobile Push Notifications

Receive push notifications on the Helix mobile app.

## Supported platforms

- iOS 15+
- Android 9+

## Setup

1. Install the Helix mobile app from the App Store or Google Play.
2. Sign in with your Helix credentials.
3. Allow notifications when prompted.

## What you can receive

- View runs
- Approve manual steps
- Receive notifications

## What mobile cannot do

The mobile app is read-and-approve only:

- Cannot edit workflows
- Cannot manage integrations
- Cannot manage billing

For these actions, use the web app.

## Quiet hours

Set quiet hours under **Mobile app → Settings → Quiet hours** to suppress notifications during specified times.

## Notification grouping

Multiple notifications from the same workflow are grouped on iOS and Android to avoid notification floods.
