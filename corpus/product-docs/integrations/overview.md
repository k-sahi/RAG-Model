# Integrations Overview

Helix connects to **10+** business apps out of the box, plus custom webhooks and HTTP for anything else.

## Supported integrations

- Slack
- Salesforce
- HubSpot
- Stripe
- Google Drive
- GitHub
- Jira
- Zendesk
- Notion
- Asana

## Connecting an integration

1. Navigate to **Integrations** in the sidebar.
2. Click **Connect** on the integration you want.
3. Authorize via OAuth (most apps) or paste your API key (some apps).
4. Name the connection and save.

## Multiple connections

You can have multiple connections to the same integration. For example, two Slack workspaces or two Salesforce orgs. When building a workflow, you choose which connection to use.

## Connection health

Helix periodically checks each connection. If a connection has expired or been revoked, you will see a red dot next to it and any workflows using it will pause until the connection is restored.

## Plan availability

- **Starter** plan includes a limited set of integrations (Slack, Email, Webhooks).
- **Pro** plan includes all standard integrations.
- **Enterprise** plan includes all integrations plus custom integrations built by Helix engineering on request.
