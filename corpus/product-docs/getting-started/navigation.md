# Navigating Helix

The Helix interface is organized into five main sections, accessible from the left sidebar.

## Workflows

Your library of workflows. From here you can create new workflows, edit existing ones, view run history, and toggle workflows on or off.

## Runs

A unified view of every workflow run across your workspace. Filter by status (success, failure, running), workflow name, or date range. Click any run to see step-by-step execution details.

## Integrations

Manage connections to third-party services. Connect new integrations, view authorization status, and rotate credentials.

## Templates

Pre-built workflows you can install with one click. Templates are organized by use case (sales, support, ops, marketing).

## Settings

Workspace, team, billing, and security settings. Only Admins and Owners see all settings; Editors and Viewers see a reduced set.

## Top bar

The top bar contains the workspace switcher (if you belong to multiple workspaces), notifications, and your profile menu.
