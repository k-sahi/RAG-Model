# Dashboards

Visualize workflow performance and run metrics.

## Default dashboards

Every workspace gets these out of the box:

- **Run volume** — runs per day, per workflow
- **Run success rate** — % succeeded vs failed
- **Run duration** — p50, p95, p99 latency
- **Top failures** — workflows with most failures, with sample errors

## Custom dashboards

**Analytics → Dashboards → New**. Drag widgets from the library:

- Run count
- Success rate
- Duration histograms
- Step-level breakdowns
- Custom metrics (defined via the API)

## Filters

Apply filters at the dashboard level (date range, workflow, user) or per-widget.

## Sharing dashboards

Dashboards are workspace-visible by default. To share externally, use **Share** to generate a public read-only link with optional password protection.

## Exporting

Dashboards can be exported as PNG, PDF, or scheduled email digests.
