# Mobile App Limitations

Known limitations of the Helix mobile app, by design and by current state.

## Cannot edit workflows

The workflow builder is web-only. To edit a workflow on mobile, you would need an external browser; Helix does not redirect to the builder from the mobile app.

## Cannot manage integrations

Connecting or disconnecting integrations must be done in the web app. The mobile app shows your existing connections but does not allow changes.

## Cannot manage billing

Billing settings, plan changes, and payment methods are web-only.

## Cannot view audit log

Audit log access is web-only. This is an Enterprise feature, and we expect customers needing audit log access to be on a desktop for compliance review.

## Limited search

Mobile search currently covers workflow names and run IDs only. Full-text search across run logs is web-only.

## Limited dashboards

Dashboards are view-only on mobile and limited to the default dashboards. Custom dashboards are web-only.

## Roadmap

Some of these limitations are planned to be removed:

- Audit log mobile view (planned Q2)
- Custom dashboard mobile rendering (planned Q3)

Workflow editing on mobile is **not** on the roadmap. We've heard the request and decided against it.
